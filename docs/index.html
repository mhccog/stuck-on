      How this works

      Every point of light is one open problem that someone has written down in public. Nothing here is invented: each one links back to the page it came from. Problems are grouped into constellations by field.

      How bright

      For each named problem we count public signs of work over the last 24 months: papers (arXiv for maths, computing and physics; Europe PMC for life, health, chemistry and earth sciences; OpenAlex for the rest), GitHub repositories, and Hacker News stories or comments that mention it by name. Brightness is the rank within its own source, so a glow means "quieter than most problems from the same list", not "nobody on Earth works on this".

      • Gap Map gaps are ranked by how many capabilities and resources Gap Map itself lists against them.
      • Papers ("stated in a recent paper") are ranked by how often that paper has been cited so far.
      • Erdős problems without a common name are ranked only by the community database: Lean formalisation, OEIS links and how recently their status was touched.
      • Problems without a short searchable name show as rings: not yet measured.

      Honest limits

      • "Open" is only as good as the list it came from. Lists lag the literature, and some problems here may already be solved.
      • Name matching is literal. A problem known by several names may look quieter than it is; a common phrase may look busier.
      • English-language sources only, for now.
      • "Who's working on it" shows public papers, repositories and threads, never contact details. There is no messaging here.
      • Skipped: the UIA Encyclopedia of World Problems. Its open API sits behind a bot check and UIA's data-extraction terms forbid redistribution, so we left it out rather than scrape it.
